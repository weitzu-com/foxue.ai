# 全球佛典覆盖登记册（GBCR）

本目录是 foxue.ai “收录 99% 佛经”承诺的可审计基础。当前发布版为 `registry-v2.7.0.json`；`source-snapshots-v0.4.0.json` 保存 CBETA、SuttaCentral、BDRC 德格甘珠尔、DSBC 与 GRETIL 的固定候选库存。逐条清单分别冻结大正藏 T01–T17 和德格甘珠尔初印本的来源标识、定位证据及完整性摘要；梵文阶段只冻结 DSBC 目录聚合摘要与 GRETIL 固定 Git 文件聚合摘要，不复制其目录或正文。`cross-catalog-alignments-v0.5.0.json` 连接已有人工证据的 CBETA 关系组、84000 Toh 引用与固定德格表达式；`84000-rights-policy-v0.3.0.json` 与 `sanskrit-rights-policy-v0.4.0.json` 分别保存 84000、DSBC 和 GRETIL 的权利边界。网页与 API 都由这些受控文件生成，旧版本永久保留。

## 统计纪律

- 目录、完整原文、稳定段落、译文、权利和质量分别统计。
- 摘录不算完整原文；外部项目已翻译不算 foxue.ai 已收录。
- 完整原文只有在受控文件、来源提交、权利决定、结构校验与 SHA-256 同时存在时才计数；当前为 978 个可追踪作品实体、1,141 个文本表达或见证，其中 1,127 个是完整全文记录，14 个是完整保存来源文件的节译、后分、节本、短本或残篇见证，共 1,683,984 个稳定行段。584 个汉译作品实体明确标为暂定书目实体，不能解读为已完成作品级去重。
- 未知分母保持 `null`，绝不按零处理或推算总体百分比。
- Work（规范作品）、Expression（语言与译本）和 Witness（具体写本或版本）分层去重。

## 完整性

每次修改登记册后运行：

```bash
pnpm verify:corpus
```

从受控目录确定性重建并核对当前登记册：

```bash
pnpm build:corpus-catalog
pnpm verify:corpus-catalog
```

校验器会检查结构、唯一标识、来源快照、统计纪律和 SHA-256 校验和。版本发布时不得覆盖旧文件，应新增版本并保留历史。

联网复算 CBETA 与 SuttaCentral 固定提交，并验证本地冻结的 BDRC 德格甘珠尔和梵文来源快照：

```bash
pnpm verify:upstream-snapshots
pnpm verify:bdrc-derge
pnpm verify:sanskrit
pnpm verify:cross-catalog
```

如需从 BDRC、IIIF 与 84000 官方端点重新抓取证据并生成新快照，运行 `pnpm snapshot:bdrc-derge`；如需从 DSBC 与 GitHub 官方端点重新生成梵文聚合快照，运行 `pnpm snapshot:sanskrit`。两类写入操作都必须在提交前人工审阅差异。上述检查不会把文件、章节、目录项或单一版本表达式自动升级为独立作品。

## 权利边界

代码许可证不覆盖佛典、译文、图像或第三方元数据。登记册中的权利状态只是审核记录，不替代来源方的正式许可。未知或混合许可必须保持保守状态，直到逐对象核验。
