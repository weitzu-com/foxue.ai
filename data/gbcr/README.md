# 全球佛典覆盖登记册（GBCR）

本目录是 foxue.ai “收录 99% 佛经”承诺的可审计基础。当前发布版为 `registry-v0.5.0.json`；`source-snapshots-v0.2.1.json` 保存固定上游提交的候选记录库存；`cbeta-taisho-sutra-inventory-v0.2.1.json` 逐条冻结大正藏 T01–T17 的路径、Git 对象哈希和字节数。网页与 API 都由这些受控文件生成，旧版本永久保留。

## 统计纪律

- 目录、完整原文、稳定段落、译文、权利和质量分别统计。
- 摘录不算完整原文；外部项目已翻译不算 foxue.ai 已收录。
- 完整原文只有在受控文件、来源提交、权利决定、结构校验与 SHA-256 同时存在时才计数；当前为 20 部去重作品、24 个完整文本表达、323,555 个稳定行段。
- 未知分母保持 `null`，绝不按零处理或推算总体百分比。
- Work（规范作品）、Expression（语言与译本）和 Witness（具体写本或版本）分层去重。
- 只有冻结来源版本、公开纳入排除规则并通过独立复核后，才允许发布全球百分比。
- 大正藏 T01–T17 的 881 条汉译经藏候选文本记录合计 247,280,257 个上游字节，是阶段性、可复算的来源分母；23/881（2.61%）只表示受控来源记录进度，不是去重作品覆盖率，更不是全球 99% 覆盖率。受控文件按上游字节计为 58,444,300（23.63%）。
- 《楞伽经》T0670、T0671、T0672 作为同一规范作品的三个汉译文本表达登记，证明作品数与文本文件数必须分开。
- 《华严经》T0278/T0279 与《大般涅槃经》T0374/T0375 分别归并为同一作品的多个文本表达；物理文件、文本表达与规范作品不可混为一层。

## 完整性

每次修改登记册后运行：

```bash
pnpm verify:corpus
```

从受控目录确定性重建并核对当前登记册：

```bash
pnpm build:corpus-catalog
pnpm verify:corpus-catalog
```

校验器会检查结构、唯一标识、来源快照、统计纪律和 SHA-256 校验和。版本发布时不得覆盖旧文件，应新增版本并保留历史。

联网复算 CBETA 与 SuttaCentral 固定提交的候选记录：

```bash
pnpm verify:upstream-snapshots
```

该检查验证固定 Git tree、提取规则和候选路径摘要，但不会把文件或章节记录自动升级为独立作品。

## 权利边界

代码许可证不覆盖佛典、译文、图像或第三方元数据。登记册中的权利状态只是审核记录，不替代来源方的正式许可。未知或混合许可必须保持保守状态，直到逐对象核验。
