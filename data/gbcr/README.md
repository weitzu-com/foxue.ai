# 全球佛典覆盖登记册（GBCR）

本目录是 foxue.ai “收录 99% 佛经”承诺的可审计基础。当前发布版为 `registry-v5.1.0.json`；`source-snapshots-v2.1.0.json` 保存 CBETA、SuttaCentral、BDRC 德格甘珠尔、DSBC、GRETIL 与 rKTs 多版本目录的固定候选库存。逐条清单冻结大正藏 T01–T33 和德格甘珠尔初印本的来源标识、定位证据及完整性摘要；T18–T21 密教部、T22–T24 律部及 T25–T33 释经论、毘昙、中观、瑜伽、论集与经疏部均有独立来源清单和责任边界审计。`gretil-sanskrit-file-rights-audit-v0.7.0.json` 对 417 份梵文佛教 HTML 逐文件保存题名、固定 Git 身份、哈希、权利信号、保守分类与外链，但不复制正文；SuttaCentral 的印度语、巴利律藏与巴利论藏权利账本逐项连接官方公共领域政策、出版或版本元数据和 Git 指纹，并明确排除第三方译文与模型训练；汉—巴关系账本、80 项双人复核队列与 20 项 P0 审前证据包只提供可复核证据，当前 0 项自动归并；rKTs 与跨目录账本保存候选连接但不自动合并作品。网页与 API 都由这些受控文件生成，旧版本永久保留。

## 统计纪律

- 目录、完整原文、稳定段落、译文、权利和质量分别统计。
- 摘录不算完整原文；外部项目已翻译不算 foxue.ai 已收录。
- 完整原文只有在受控文件、来源提交、权利决定、结构校验与 SHA-256 同时存在时才计数；当前为 1,854 个可追踪作品实体、2,072 个文本表达或见证，其中 2,029 个是完整全文记录，43 个是完整保存来源文件的节译、后分、节本、短本、残篇、组件、局部、分离、版本或已知缺文见证，共 3,150,950 个稳定行段。1,262 个汉译作品实体明确标为暂定书目实体，不能解读为已完成作品级去重。
- 未知分母保持 `null`，绝不按零处理或推算总体百分比。
- Work（规范作品）、Expression（语言与译本）和 Witness（具体写本或版本）分层去重。
- 只有冻结来源版本、公开纳入排除规则并通过独立复核后，才允许发布全球百分比。

## 完整性

每次修改登记册后运行：

```bash
pnpm verify:corpus
```

从受控目录确定性重建并核对当前登记册：

```bash
pnpm build:corpus-catalog
pnpm verify:corpus-catalog
```

校验器会检查结构、唯一标识、来源快照、统计纪律和 SHA-256 校验和。版本发布时不得覆盖旧文件，应新增版本并保留历史。

联网复算 CBETA 与 SuttaCentral 固定提交，并验证本地冻结的 BDRC 德格甘珠尔和梵文来源快照：

```bash
pnpm verify:upstream-snapshots
pnpm verify:bdrc-derge
pnpm verify:sanskrit
pnpm verify:rkts
pnpm verify:rkts-kernel-alignments
pnpm verify:cross-catalog
pnpm verify:suttacentral-parallels
pnpm verify:suttacentral-parallel-review-queue
```

如需从 BDRC、IIIF 与 84000 官方端点重新抓取证据并生成新快照，运行 `pnpm snapshot:bdrc-derge`；如需从 DSBC 与 GitHub 官方端点重新生成梵文聚合快照，运行 `pnpm snapshot:sanskrit`；如需从 rKTs 两个固定 Git 仓库重建多版本目录快照，运行 `pnpm snapshot:rkts`。写入操作都必须在提交前人工审阅差异。上述检查不会把文件、章节、目录项或单一版本表达式自动升级为独立作品。

## 权利边界

代码许可证不覆盖佛典、译文、图像或第三方元数据。登记册中的权利状态只是审核记录，不替代来源方的正式许可。未知或混合许可必须保持保守状态，直到逐对象核验。
